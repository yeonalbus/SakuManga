# SakuManga v2.4.0

> 自 v2.3.0（2026-10-31）以来共 88 个提交。本版围绕**离线库可靠性与交互体验重构**展开：**维护查重与忽略体系升级**（5 行卡片 + 展开区页预览缩略图墙与灯箱 + 社区评分、按组成员忽略与定向过滤、跨画师误报与快照问题修复）、**扫描/入库契约重构与路径级联清理**（D1–D22 单层切分 / `page_cache_v2` / 来源不可变 / 两阶段原子删除 / 扫描路径级联清理）、**失效本子恢复与阵亡双轨生命周期**（扫描失效对账 + 恢复会话 + 404 确定性失败入阵亡 + 候选软隐藏）、以及**离线详情页通栏三 Tab 改版**、书签页筛选搜索与推荐算法优化。另有 AGPL-3.0 规范化、GitHub Pages 展示页、CI 自动化与演示截图流水线落地。数据库由启动时 AutoMigrate 自动迁移，升级仅需替换 exe 或换镜像标签。

## ✨ 新增功能

### 维护查重与忽略体系（Round50–52）

- **维护成员卡改版与页预览缩略图墙**（`PageThumbWall.vue`、`PageLightbox.vue`、`usePagePreview.ts`、`page_thumb.go`）：成员卡固定两列 5 行布局、标题固定两行、封面 3:4 撑满高度，新增社区评分字段与决策标签排序；展开区新增成员切换条、页预览缩略图墙与灯箱，不进对比页即可核对画面差异
- **维护页批量移除与忽略多选恢复**：维护页支持勾选批量移除并去除全局删除锁，忽略清单（`OfflineIgnore.vue`）支持多选批量恢复

### 扫描与入库契约重构（D1–D22 + Round53）

- **扫描边界与页索引收敛**：扫描边界改为单层切分 + 递归统计页数 + 隐藏页相对路径（`page_hide_relpath_test.go`、`comic_hidden_pages_test.go`），页缩略图缓存目录隔离至 `page_cache_v2`
- **入库白名单与来源不可变**：扫描落库改为三类字段白名单；仅首次入库写来源，已存在记录不改写（来源不可变），来源标签区分已移除来源并在详情返回
- **原子删除与元数据优先级**：重构两阶段原子删除与关联表清理，统一侧车元数据优先级，扫描统计按原因细分；前端契约收敛（`tags` 统一 `TagItem[]`、页数兜底 0）
- **扫描路径级联清理**（Round53）：删除扫描路径时级联清理该路径下已入库漫画，前端移除前弹出二次确认并展示将清理的本数；补充 `cleanup_orphan_scanpaths` 与 `cleanup_unsupported_archives` 调试清理工具

### 失效本子恢复与阵亡双轨生命周期（Round54 + Round56）

- **扫描失效对账与数据层**（`models/recovery.go`）：新增 `RecoveryCandidate` 与 `FallenComic` 两张表，全量扫描自动对账失效记录并按 `g_id`（无 `g_id` 则按 `cid`）去重落库
- **恢复会话与前端入口**（`services/recovery.go`、`handlers/recovery.go`、`RecoveryDialog.vue`、`FallenMenu.vue`）：提供恢复会话状态/启动/取消/扫描锁与完成/失败钩子，前端支持恢复/阵亡按钮与档位弹窗
- **阵亡名单与双轨生命周期**（`services/trash.go`）：`archiver.php` 404 归入确定性失败并计入阵亡名单，支持异常恢复任务一键转入阵亡（含存量 404 任务处理入口）；实现本地失效本子双轨生命周期（阵亡清理与候选软隐藏）

### 离线 UI、书签与推荐（Round55–56）

- **离线详情页通栏三 Tab**：`OfflineDetail.vue` 信息区改为通栏三 Tab，新增全站评分、书架浮层与 Tag 联想
- **离线侧栏书架分组**：对齐书签极简布局
- **书签页筛选与智能回显**（`bookmarkPrefill.ts`）：书签页新增筛选搜索、重命名预填充与创建智能回显
- **偏好信号与推荐算法优化**：优化个人偏好信号、综合偏好榜与推荐算法

### 工程与社区展示基建

- **GitHub Pages 与预览资产**：新增 `docs/index.html` 单文件项目展示页、`docs/social-preview.png` 与 OG 元标签；新增演示数据服务与 Playwright 自动截图流水线（`demo/`、`npm run demo:shots`）
- **CI 与社区规范**：新增 `.github/workflows/ci.yml` 前后端自动化测试与构建校验工作流、Issue/PR 模板，并将 `LICENSE` 规范化为标准 AGPL-3.0 原文

## 🛠️ 优化改进

- **忽略语义与查重性能**：忽略语义改为按组成员（Round51），忽略与确认新增改为定向过滤、恢复忽略后立即本地重算，不再全量重算聚类；删除检测层无用的 `forceFull` 死参数，删除改为定向裁剪
- **解压与入库容错**：压缩包解压支持剥离单一顶层目录，入库失败置任务 `error`；解压失败改回可重试，不再计入阵亡
- **维护开关语义锁定**：修复关闭离线维护不生效问题，锁定维护开关双维度语义
- **标签写回剔除**：剔除标签每周反向写回 ComicInfo 功能（Round55）
- **手柄提示**：阅读器未检测到手柄时，提示补充按键唤醒与充电说明

## ⚠️ 已知问题

- **更新探测依赖 E 站凭据**：未绑定或凭据失效的用户会被跳过并记录日志（不会误标红点）
- **书签页极窄屏仍偏挤**：三列 → 两列（1100px）→ 单列（720px），`<720px` 时卡片较窄
- **「加载较新内容」锚点卡列位可能横跳一格**：E 站每页 25 张与列数不整除（v2.2.0 起既有，垂直位置精确保持）
- **维护页疑似重复 / 推荐算法**相关单测在部分运行顺序下存在既有偶发失败
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- **Windows exe**：下载 `SakuManga.exe` 双击运行（单文件内嵌前端 + 后端 + 自定义图标），运行后最小化到系统托盘，右键托盘图标可选「打开界面 / 退出程序」
- **Docker（推荐 NAS / Linux 长期运行）**：

  ```bash
  docker run -d --name sakumanga --restart unless-stopped \
    -p 8081:8081 \
    -v /your/data/dir:/app \
    ghcr.io/yeonalbus/sakumanga:2.4.0
  ```

  镜像同时提供 `linux/amd64` 与 `linux/arm64`，标签策略 `2.4.0` / `2.4` / `latest`；数据（`manga.db` / `config.json` / `data/` / `logs/`）全部保存在挂载目录，升级 = 换标签重建容器。完整说明见 [`DSPlans/VerNotes/wiki.md`](wiki.md)「九、Docker 部署」
- **纯后端（NAS 无 Docker 环境）**：`SakuManga.exe --headless`
- 默认监听端口 `8081`（「设置 → E 站连接 → 网络」可改），被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「账户」中修改
- **升级安装**：exe 方式直接替换文件；Docker 方式换镜像标签重建容器。数据均自动保留，数据库结构由启动时自动迁移（本版新增 `recovery_candidates` / `fallen_comics` 两张表及社区评分等字段，并在启动时自动清理跨画师旧忽略；**建议升级前备份 `manga.db`**）。页缩略图缓存目录已切换为 `page_cache_v2`，旧 `page_cache` 目录可按需手动清理
