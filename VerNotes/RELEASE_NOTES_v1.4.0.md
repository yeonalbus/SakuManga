# SakuHentai v1.4.0

> 自 v1.3.2（2026-08-09）以来共 62 个提交，本版为**功能 + 修复大汇总**：新增书架自定义排序 / 书架置顶与全部书架检索浮层 / 视口诊断面板，完善手柄操作与阅读器主题联动，并系统性修复 iPad PWA 布局与返回链路、离线历史重复显示、抽卡离线 tag 失配、书架「找不到该漫画」报错等问题。数据库结构由启动时 AutoMigrate 平滑迁移，升级无需手动处理。

## ✨ 新增功能

- **书架自定义排序**：书架列表与书架内项目均支持 ↑/↓ 调整顺序，顺序持久化到后端（Round10）
- **书架置顶 + 全部书架检索浮层**：侧栏常驻展示置顶书架（最多 5 个），其余书架进「🔍 全部书架」浮层检索导航；离线多选可快捷批量加入书架（Round13）
- **视口诊断面板 `/diag`**：管理员入口，实时展示视口 / dvh / safe-area 等布局数据，用于 iPad PWA 底部条类问题排查（Round18）
- **离线历史按 gid 合并去重**：更新替换 / 重扫换 id 后同一本子不再在历史网格重复显示；漫画被删除/替换时自动迁移或清理历史、书架、阅读清单引用（Round20）
- **离线/在线 tag 筛选统一**：本地匹配理解 E-Hentai 线上语法（`female:"magical girl$"` → `$` 精确、无 `$` 前缀），Tag 联想/点击统一按线上格式插入，抽卡与书库搜索离线/在线共用同一语义（Round20）

## 🛠️ 优化改进

- 阅读器颜色跟随全局主题（深色→深色、浅色→浅色），不再恒定深色（Round19）
- 离线封面缩略图缓存：ZIP/CBZ 不再反复解压整包，带 Cache-Control/ETag，二次进入零请求（Round14）
- 移除下载完成后自动全库扫描（改为维护自动比对），减少无谓联网与 IO
- 在线评分支持半星解析、页数解析修复（上传者数字与页数拼接不再误取）
- 手柄操作增强：阅读器双击快速切本（上下均支持）、确认/取消按键可自定义防与翻页冲突
- 离线详情页：改标题（支持恢复原标题）、本地备注、预览切片、一键跳转在线版本
- 书架内容可一键导入离线阅读清单；下载完成桌面提示
- 小详情面板展开/收起滚动补偿：点开画廊保持视线焦点，修复 iPad 面板切换乱滑动
- 侧栏整体滚动 + 返回保留书架 id（fullPath），从书架进详情返回不再丢失定位

## 🐛 Bug 修复

- **iPad PWA 底部条 / 横屏黑边**：多轮迭代收敛（100vh/dvh 高度链 + safe-area 避让 + orientationchange 重算），底部黑边与横屏黑边消除（Round15/16/17/18）
- **iPad PWA 返回刷新**：PWA 下不再使用受限的 window.open，改同标签 SPA 跳转 + 来源状态记录，返回不刷新、恢复来源列表页码与滚动位置；根治 PWA 整页导航逃逸到 Safari（Round15/16/17）
- **订阅界面显示首页内容**：订阅（Watched）固定指向 e-hentai 表站，EX 账号也能正常读取订阅列表（Round15-Bug2）
- **阅读器显示全局外壳**：/reader 路由隐藏顶部搜索栏与侧栏 logo，阅读器保持沉浸全屏（Round15-Bug4）
- **搜索历史不收起**：移动端键盘收起时（blur / visualViewport 高度恢复）自动关闭搜索联想面板（Round15-Bug5）
- **离线历史重复显示**：同 gid 不同 id（更新替换产生）的历史合并为一条；删除/替换漫画时同步清理历史/书架/阅读清单引用（Round20-Bug1）
- **抽卡离线 tag 失配**：`female:"magical girl$"` 等线上格式不再筛不出本地 `female:magical girl`（Round20-Bug3）
- **书架「找不到该漫画 / 已被删除」报错**：404 时自动刷新列表并清理孤儿引用，弹窗不再跨书架残留；离线列表拉取失败给出可见提示（Round20-Bug4）
- **在线阅读加载失败白屏**：页列表获取失败（含 gdata 无 file 标签回退 / 会话失效 / 限流）给出明确错误层（重试/返回）与状态码映射（401/429/410/403）；离线模式误打开纯数字 gid 时无 token 也自动解析并切换在线模式（Round20-Bug2）
- **离线评分丢失 / 星级筛选**：书架切换后评分不丢，星级筛选按「生效评分」（个人评分优先）过滤
- **历史空值保护**：阅读器进度写回不再把历史标题/封面污染成 gid 乱码或无封面

## ⚠️ 已知问题

- 在线列表负向排除为「本地丢弃」，命中条目较多时单页显示条数变少（游标继续加载）

- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuHentai.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「高级设置」中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「安全」中修改
- NAS / 无界面环境请使用 `SakuHentai.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuHentai.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；数据库结构由启动时自动迁移，无需手动处理
