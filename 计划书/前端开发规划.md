# 多端适配与设备适配（实现完成，待真机验证）

## 一、多端适配（手机 / iPad，PC 原生开发不变）

### 响应式基础设施

- `index.html`：viewport 增加 `viewport-fit=cover`、`theme-color`、iOS PWA meta、manifest 链接
- `App.vue`：`:root` 增加断点变量 `--bp-tablet: 768px` / `--bp-phone: 480px` 与 `--safe-*` 安全区变量；`html,body { touch-action: manipulation; overscroll-behavior-y: none }`；`.app-container { height: 100dvh }`（动态视口，防移动端地址栏跳动）

### 布局（汉堡抽屉方案）

- `App.vue`：窄屏（<768px）侧边栏收起为左侧抽屉（`translateX(-100%)`）+ 左上角汉堡按钮（z-index 70 > 侧边栏 65 > 遮罩 60），宽屏自动展开
- `TopBar.vue`：窄屏顶栏让位汉堡按钮（padding-left 56px + safe-area）

### 通用组件窄屏适配

- `ReadingList.vue` / `FilterDrawer.vue`：窄屏抽屉 100vw + 底部安全区
- `Pagination.vue`：窄屏隐藏 offset / 翻页按钮
- `GridContainer.vue`：卡片模式 桌面 4 列 → ≤1024px 3 列 → ≤768px 2 列；compact 模式 ≤480px 单列

### 阅读器移动端优化

- `ComicReader.vue`：`@media (max-width: 767px)` 安全区 padding、标题 36vw 截断、点击热区 72px→56px、设置抽屉 100vw、底部安全区

### PWA 全屏

- `public/manifest.webmanifest`：standalone、theme #121212、icons
- `public/apple-touch-icon.png`（`scripts/gen-pwa-icon.mjs` 纯 Node 生成 180x180 占位图标）
- `index.html` iOS meta（apple-mobile-web-app-capable / apple-touch-icon）

## 二、设备适配（8BitDo Micro 手柄 + 滑动翻页）

### 手柄控制（Gamepad API，iOS Safari 16.4+）

- `src/stores/readerSettings.ts`：`GAMEPAD_BUTTONS` 标准按键索引常量 + 手柄设置字段（enableGamepad / gamepadNextKeys / gamepadPrevKeys / gamepadToggleKeys）+ 默认键位
- `src/composables/useGamepad.ts`：rAF 轮询 + gamepadconnected/disconnected 事件、按键上升沿检测（防连发）、依据开关自动启停
- `ComicReader.vue`：`turnByPhysicalDirection` 物理方向翻页（自动兼容 RTL 反转与 Webtoon 滚动），手柄 D-Pad右/A=下一页、D-Pad左/B=上一页、Start/Select=设置；悬浮顶栏显示 🎮 连接状态
- `ReaderSettings.vue`：🎮 游戏手柄设置区——启用开关、连接状态、键位映射（8BitDo Micro 预设 + 点击录制自定义）、键位 chip 可删除

### 滑动翻页（基础版）

- `ComicReader.vue`：canvas-stage 触摸滑动（横向位移 ≥60px 且明显大于纵向），向左滑=下一页、向右滑=上一页；`touch-action: pan-y`；捕获阶段拦截滑动后误点击；与拖拽放大/点击热区做手势仲裁
