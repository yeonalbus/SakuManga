# SakuManga v2.1.0

> 自 v2.0.1（2026-08）以来共 44 个提交，本版为**本地库智能化 + 稳定性收敛版**：新增本地 XP 词云与偏好推荐、搜刮书签多端同步与「锚定即记录」、离线长任务暂停 / 继续 / 取消；修复「维护查重忽略或删除后必须重新扫描一遍」「书签静默丢失 / 多端不同步」等问题。数据库结构由启动时 AutoMigrate 平滑迁移（新增书签表与 XP 统计表），升级仅需替换 exe。

## ✨ 新增功能

- **XP 词云**：本地排行榜页升级为「📊 阅读榜 | ☁️ XP 词云」双视图——按标签命名空间分段展示**核心 XP**（female / male / mixed）、**角色原作**（character / parody）与**其他**，并区分**库藏口径**（搜集广度，每本计 1）与**阅读口径**（按阅读信号加权，暴露覆盖率避免误读）；画师 / 社团因长尾分散剥离为独立的 **Top 20 榜单**
- **本地偏好推荐**：随机抽卡页新增「🎲 纯随机 | ✨ 偏好推荐」卡池模式，按词云权重加权采样，参数可调（偏好侧重 θ / 探索率 ε / 温度 T / 排除已读 / 排除书架已有）；**仅作用于本地库**，在线部分保持纯随机并在界面明确标注
- **搜刮书签多端同步**：书签从浏览器本地存储迁至后端（按账号隔离，与历史 / 书架 / 评分同模式），PC 与手机互相同步；旧本地数据首次登录自动迁移，后端不可用时降级读取本地缓存并给出提示
- **搜刮书签「锚定即记录」**：点「存为书签」直接进入拾取模式，点选卡片后自动带出**发布时间**（E 站 posted 日期）与**位置信息**（首页 / 搜索词），名称可留空
- **离线长任务暂停 / 继续 / 取消**：更新检测与维护查重支持中途暂停、继续与取消（协作式，当前漫画处理完成后生效），长任务不再「一旦开跑只能等」
- **新版本检测提醒**：设置 → 关于软件 集成 GitHub 新版检测，发现新版本时给出红点与提示
- **阅读器页码角标**：阅读器右下角常驻当前页 / 总页数（如 `20/49`）

## 🛠️ 优化改进

- **忽略 / 删除即时生效，无需重新扫描**：维护查重中忽略疑似重复组、恢复忽略、删除条目后，结果列表即时更新（此前被忽略的组重进页面会「复活」、删除后必须整份重扫）；定向重算只跑纯本地聚类，毫秒级完成
- **搜刮书签侧栏排版**：改为邮件列表式两行布局（主文本 + 日期、副文本 + 时间右对齐），图标精简、悬停显示删除；锚定卡片信息区改为**金色底高亮**（深色主题暗金 / 浅色主题亮金，封面与文字不受影响）
- **父画廊查重增强**：支持**隔代祖孙关系**与父链上溯——本地只保存更新链两端（中间版本缺失）时不再漏判「旧版被取代」
- **接口性能优化**：离线漫画列表与标签词典接口加载更快
- **XP 词云视觉改版**：留白与椭圆轮廓布局、字号层次、配色景深与文本治理（emoji / 图标 markdown 剥离、双语标签取短侧）
- **本地排行榜卡片**：只显示标题并固定两行高度，列表更整齐
- **工程基线**：oxlint / eslint 全量通过（修复既有 lint 基线问题）

## 🐛 Bug 修复

- **搜刮书签数据静默丢失**：恢复校验过严会把异常书签整条丢弃且无任何提示——现改为宽松兜底（缺失字段补默认值、损坏配置补空对象），书签照常展示；写失败给出明确提示
- **多端书签不同步**：书签只存浏览器本地存储，设备之间天然隔离——现后端化按账号隔离
- **锚点失效提示含糊**：书签锚定的画廊被删除 / 更换时提示不清，现明确为「书签已保留，跳转仅恢复位置」并在侧栏标记 ⚠️
- **维护查重「忽略后复活」**：忽略的疑似重复组重进页面又出现、恢复的组不出现（后端结果缓存未随忽略表更新）——现忽略 / 恢复 / 删除三个入口均定向同步结果缓存
- **删除后被迫重扫**：删除条目后结果被标记过期、进入页面反复提示「请重新扫描」——现定向剪除已删项（含其配对项）并重算疑似重复组，结果即时可信
- **EH 网站设置页重复显示资产卡片**：修复设置页资产卡片重复渲染
- **书架排序按钮样式**：取消与完成排序按钮统一为 header 操作按钮样式

## ⚠️ 已知问题

- **「疑似重复」簇暂不支持勾选删除**：目前只支持「忽略」（可随时从忽略清单恢复），删除入口仅在强证据的「建议删除」区提供；疑似重复的勾选删除能力将在后续更新中补全（详见常见问题手册）
- **父子画廊关系的建立时机**：本地导入 / 扫描入库的书若缺少 E 站元数据（metadata / ComicInfo），父子关系需跑一次联网的「维护查重」才会建立（导入不会自动联网）；且**全量重新扫描**额外路径会把此前建立的父子关系重置，需再跑一次维护查重恢复（增量扫描不受影响）
- **搜刮书签锚点定位**：依赖目标列表已加载；画廊被删除 / 更换为子画廊时定位失败（书签本身保留，侧栏标记 ⚠️，跳转仅恢复位置）
- 在线列表负向排除仍为「本地丢弃」，命中条目较多时单页显示条数变少（游标继续加载）
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuManga.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「E 站连接 → 网络」中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「账户」中修改
- NAS / 无界面环境请使用 `SakuManga.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuManga.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；数据库结构由启动时自动迁移，无需手动处理
