# SakuManga v2.0.0

> 自 v1.4.0（2026-08-22）以来共 71 个提交。本版为**里程碑大版本**：项目正式由 SakuHentai 更名为 **SakuManga**（包名 / Go 模块 / exe / 界面标题 / 文档全量同步），版本号升至 2.0.0；同时落地画质升级、搜刮书签、查重增强（疑似重复自动分组 + 忽略标记）、阅读器升级、下载方案四选一等一批新能力，并完成安全凭据整改。数据库结构由启动时 AutoMigrate 平滑迁移（新增 `ignored_identifiers` 表），升级无需手动处理。

## ✨ 新增功能

- **项目更名 SakuManga**：项目、包名、Go 模块、可执行文件名（`SakuManga.exe`）、界面标题与全部文档统一更名为 SakuManga（v2.0.0 MAJOR 依据）
- **图片质量升级**：自动检测本地非「归档原图」版本（如画廊版/压缩版）并提供升级入口——重新下载归档原图并原子替换本地文件，历史 / 书架 / 评分完整保留；**开放给所有登录用户**（此前仅管理员）；存量本子按「任务记录优先 + 目录形态兜底」自动推断下载方案（归档视为原图、画廊视为画廊下载）（Round-T3）
- **搜刮书签**（Round27）：在线浏览任意位置可「存为书签」——首页 / 搜索两类，快照当时的搜索词与全部筛选状态，并可锚定一张画廊卡片；点击书签一键恢复筛选并滚动定位锚点卡片（角标 + 脉冲高亮），桌面新标签 / PWA 同标签分流
- **名称级疑似重复自动分组**（Round26-O3）：维护查重新增「疑似重复」区——按「核心名 + 画师 + 卷号」自动聚类多语言版本 / 重传补档 / 版本变体（重绘、新装版等），高置信 / 中置信两档标注；智能清洗展会届数、DL 版、汉化组名、语言后缀等版本标记，卷号提取为独立特征（续集/分卷不误判）；**只出建议、不自动删除**
- **忽略标记**（Round26-O2）：疑似重复组与父画廊更新提示支持一键忽略；「🕶️ 忽略清单」弹层可随时查看 / 恢复；title 型忽略按「核心名 + 画师」记录，天然覆盖同作品全部变体
- **簇双列对比 + 成员级忽略**（Round26-2）：双列对比页左 / 右窗口标签卡（A/B/C…）可独立切换组内任意两本；「忽略本组」支持选择部分成员忽略（误判剔除）
- **维护页 UI 重构**（Round26）：按钮区重排、新增统计条（建议删除 / 疑似重复组 / 已忽略 / 建议保留）、疑似重复簇卡片横排展示
- **阅读器升级**（Round24）：物理索引重构（页序稳定）、书签 / 章节标记与侧栏、章节层级 / 大纲优化、大纲支持行内编辑（名称 / 层级 / 父级）、顶栏与阅读设置优化；隐藏页标记联动清除
- **隐藏页软删除**（Round23）：离线画廊支持自定义删除页面（隐藏页软删除）、管理模式隐藏 / 恢复页面、原生 tag 叉除恢复语义
- **下载方案四选一**：更新 / 下载方案扩展为「画廊 / 归档 × 原图 / 压缩」四选一（Round-T3 前置）
- **书架 LexoRank 排序与快捷加入扩大**（Round22 存量提交）：书架列表与书架内项目支持拖拽排序 + 「移动到第 X 位 / 快捷置顶」；快捷加入书架扩展到「手气不错」「离线历史」；书架内部支持多选批量移出
- **评论区 E-Hentai 链接解析**：评论区 e-hentai / exhentai 画廊链接可点击直达画廊详情（修复中文被吞与相邻 URL 粘连）
- **上传者跳转搜索**：在线详情点击上传者直接以该名字搜索
- **下载列表打开在线详情**：点击下载任务卡片即可打开对应画廊的在线详情
- **筛选栏连续多 Tag 输入**：点击联想项后保持输入焦点，可连续输入多个 tag
- **账号凭据可视化**：账号设置显示 pass_hash 并支持一键刷新凭证
- **归档下载线程数 1-10 全选项**：设置项补全全部档位
- **下载列表移动端两列布局**：移动端筛选区改为一行两列

## 🛠️ 优化改进

- **E 站请求自适应限流**：固定 1.2s 限流改为自适应——连续成功自动提速至 500ms（约 2 req/s），429 / 503 / 网络失败自动退避（×2 至 5s），全量在线核对耗时约减半（Round26）
- **归档分块 429 限流自动降级**：归档下载分块遇 429 识别为限流，自动降低线程数重试（Round-T3）
- **解压失败清理残留**：解压失败任务取消时删除损坏压缩包与半解压残留
- **阅读器性能与兼容**：小主机性能优化（Round24）、tag 新旧后端兼容（Round24）
- **搜索配置持久化**：搜索配置落盘并接线继承策略，搜索跳转后筛选不再重置（Round27-Bug1）
- **错误上报公开化**：前端错误上报改公开路由，并支持在日志页查看上报内容
- **详情预览分批加载**：离线详情预览切片分批加载，降低首屏压力
- **阅读器预加载统一**：预加载逻辑统一、发布前死代码清理
- **安全凭据整改**：调试工具 E 站凭据改环境变量注入并解除 JHentai 跟踪；移除验证脚本中硬编码的线上站点与测试密码

## ⚠️ 已知问题

- 跨语言翻译标题不聚类：日文原版与英文意译标题（字符层面无关）无法由名称级判定可靠聚组，属设计取舍（宁漏不误）；保留原名的 `(English)` 后缀变体可正常聚类
- 性能项 B/C 暂缓：详情请求跨任务缓存复用（数据陈旧风险）、核对窗口化（频繁增量场景反而更慢）两项未实施
- 忽略清单暂不显示「覆盖 N 个本地条目」（显示忽略时间）
- 在线列表负向排除为「本地丢弃」，命中条目较多时单页显示条数变少
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuManga.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「网络」设置中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「账户」中修改
- NAS / 无界面环境请使用 `SakuManga.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuManga.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；数据库结构由启动时自动迁移（新增 `ignored_identifiers` 表），无需手动处理
