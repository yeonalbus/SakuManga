# Round43：疑似重复（名称级）删除能力方案

> 起因：README / wiki 长期标注的限制项——「疑似重复」簇只支持「忽略」，不支持勾选删除，
> 删除入口仅在强证据的「建议删除」区提供。本次补全该能力，并明确删除后的结果语义。

## 1. 目标与红线

- 「疑似重复（名称级，仅建议 · 不自动处理）」区新增删除入口：成员级勾选批量删除 + 单卡删除。
- 成员对比页（`OfflineCompare.vue` `type=cluster`）支持删除当前成员，删除后**原地占位**。
- 红线保持：疑似重复**永远不自动删、不自动忽略**，后端不引入自动处理路径；设置里仍无「疑似重复自动处理」开关（本次只增加「人工点击」的删除入口）。

## 2. 决策记录（用户拍板）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 批量删除工具栏位置 | 疑似重复区**标题下方内嵌工具栏**（与「建议删除」区同构），勾选状态与「建议删除」区完全独立 |
| 2 | 单成员删除形态 | 成员卡片底部**两个小按钮**：「删除（保留文件）」/「删除（含文件）」，与「建议删除」区文案一致 |
| 3 | 全选策略 | **不提供「全选」按钮**：批量删除的语义 = 用户自行勾选后一键删除；同时**禁止整组删空**（每组至少保留 1 本） |
| 4 | 对比页删完不足 2 本 | 顶部横幅「该组已处理完毕」+「← 返回维护页」按钮，被删成员**占位页保留**（不自动跳走） |

勾选框按用户要求**固定在成员卡片右上角**（绝对定位叠于封面右上角，半透明底，点击不触发打开详情）。

## 3. 删除后的结果语义（需求 2）

后端**无需新增逻辑**：删除接口（`POST /offline/maintain/remove`）已调用
`InvalidateMaintainDedupResult` + `SyncMaintainDedupClusters`，后者毫秒级重跑本地名称级聚类
（`detectTitleClusters` 对 `len(组) < 2` 直接跳过）。因此：

- 组内仍有 **≥2 本** → 视为未处理完毕，继续显示（成员数收缩、置信度按新成员重算）；
- 组内只剩 **1 本** → 视为处理完毕，该组自动从列表消失（无需重新扫描）；
- 删完最后一组 → 落入「恭喜！本地画库暂无重复或异常项」空态。

本次仅补一条回归测试锁定该语义（`TestSyncMaintainDedupClustersAfterMemberRemoval`）。

## 4. 实现要点

### 4.1 维护页（`OfflineMaintain.vue`）

- 抽出共用删除实现 `doRemoveComic(comic, deleteFile)`：「建议删除」区与「疑似重复」区共用确认文案 + 幽灵文件容错，避免两处漂移。
- 新增独立勾选态 `selectedClusterIds`；`loadResult()` 后清理勾选残留（成员可能已删/已被忽略/已随簇重算消失）。
- 每组至少保留 1 本：`isClusterMemberLocked()` 在「同组已勾选 = 成员数 − 1」时禁用该组最后一本的勾选框，
  取消同组其他勾选即恢复可选；工具栏常驻说明该规则。
- 工具栏展示「已选 N 本 · 涉及 K 组」，两个删除按钮（保留文件 / 含文件）一次提交 `comicIds`。

### 4.2 对比页（`OfflineCompare.vue`）

- `ClusterMemberDTO` 增加 `deleted` / `deleteFile` 本地标记；删除按钮位于左右面板头部（就近，明确删哪一侧）。
- 删除弹层二选一：「仅删除记录（保留文件）」/「删除记录 + 本地文件」，并展示目标标题与本地路径。
- 删除成功后**不重新 `load()`**（重拉会因成员不足而报错），改为本地标记 `deleted`：
  标签卡置灰划掉且不可选中、面板换灰底占位页（🗑️ + 标题 + 删除方式）、左右索引不跳动。
- `aliveClusterMembers < 2` 时顶部横幅提示该组已处理完毕。
- 顺带修文案：命中「簇存在但成员 <2」时不再误报「结果可能已刷新，请重新扫描」。
