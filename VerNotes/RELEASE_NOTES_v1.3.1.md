# SakuHentai v1.3.1

> 自 v1.3.0 以来，聚焦在线搜索系统：f_search 标准语法自动修正、标签联想热度协同排序与多词完整命中，搜索命中率与体验显著提升；同时收敛搜索链路多处置空与联想竞态问题，并新增可本地确定性验证的 E2E 回归脚本。

## ✨ 新增功能

- 在线搜索 f_search 自动修正：输入的非标准搜索词自动规范化为 E 站标准语法，避免语法偏差导致漏搜 / 空结果
- Tag 联想 / 点击按模式生成 f_search 标准语法：在线 / 离线等模式输出对应标准语法（如 `t:... s:...`），减少手工拼写
- 标签联想按热度协同排序：候选按标签热度协同排序，贴近常用标签；支持多词输入完整命中
- 搜索新标签打开：搜索操作在新标签打开详情，联想框增加滚动条，候选上限提至 20 条

## 🛠️ 优化改进

- 新增 [`scripts/e2e-search-suggest.mjs`](../scripts/e2e-search-suggest.mjs) 搜索回归脚本：覆盖联想插入 / 懒更新 / 补全位置三问题，支持本地 MOCK 确定性验证
- 搜索联想插入 / 懒更新 / 补全位置逻辑统一，禁用 TagChip 快捷搜索避免误触发

## 🐛 Bug 修复

- 修复多 tag 连续输入联想失效
- 修复空搜索关键词误回归首页
- 修复 f_search 自动修正开关失效
- 修复标签联想命名空间误匹配
- 修复在线列表 `comics` 为 `null` 导致 `.filter / .map` 崩溃
- 修复搜索无结果时在线列表返回 `null`（改为返回空数组）

## ⚠️ 已知问题

- 在线列表负向排除为「本地丢弃」，命中条目较多时单页显示条数变少（游标继续加载）
- 抽卡负向排除后候选数量不足时仅提示，后端采样补位为后续增强
- 跨文件夹在线回填 GID 依赖已登录 IPB 账号，未绑定账号 / 无网络时额外路径无法跨文件夹识别版本
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuHentai.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「高级设置」中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「安全」中修改
- NAS / 无界面环境请使用 `SakuHentai.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuHentai.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；数据库结构由启动时自动迁移，无需手动处理
