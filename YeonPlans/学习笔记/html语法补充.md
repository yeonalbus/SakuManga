### 1. HTML 的核心语法：标签与嵌套

- **HTML 的语法结构极其规律，主要由标签（Tag）和属性（Attribute）组成：**
  - <!-- 双标签：有开头有结尾，中间包着内容 -->
  - <标签名 属性="属性值">内容</标签名>
  - <!-- 单标签：没有子内容，自闭合 -->
  - <标签名 属性="属性值" />

- **树状嵌套：大盒子套小盒子，小盒子套文本。**
  - <div class="card">
    - <h2>标题</h2>
    - <p>这是一段文本</p>
  - </div>

### 2. Vue 开发中最常用的 4 类标签

- **容器类标签（画盒子的）**
  这些标签没有任何默认的外观（或者只有很简单的边距），主要用来搭建页面骨架：

  **<div>：**
  - 最无脑、最常用的通用盒子。用来把页面划分成一块一块的区域。

  **语义化盒子（<aside> / <main> / <header> / <nav>）：**
  - 在功能和表现上与 <div> 完全一模一样，只是换了个名字，用来告诉开发人员这里是侧边栏（aside）、主体区域（main）还是导航（nav）。你在 App.vue 看到的就是它们。

- **文本展示类标签**

  **<h1> ~ <h6>：**
  - 一级到六级标题，字体默认会加粗变大。

  **<p>：**
  - 段落（Paragraph），块级文本。

  **<span>：**
  - 行内小文本。它不会独占一行，通常用来单独给一两个词加样式（比如在 App.vue 里用 <span class="logo"> 给标题单独上色）。

* **交互与表单类标签**
  **<button>：**按钮，用来响应用户点击。

  **<input>：**输入框，根据 type 属性的不同可以变成不同控件：
  - <input type="text" />：普通文本输入框
  - <input type="password" />：密码框
  - <input type="checkbox" />：勾选框

  **<a>：**超链接，用于跳转页面。（在 Vue 中通常用 <router-link> 代替，避免页面刷新）

* **列表类标签**
  **<ul> + <li>：**
  - 无序列表。<ul> 是列表外框，里面每个子项都用 <li> 包包裹。
  - 比如菜单栏、商品列表经常用它们来装载。

### 3. 属性（Attribute）是做什么的？

如果说标签决定了“这里放个什么东西”，那么属性就决定了“这个东西长什么样、有什么特性”。

常见属性：

**class="xxx"：**

- 给元素指定一个样式类名，CSS 代码就是通过这个类名给它涂颜色的。

**id="xxx"：**

- 给元素加一个全局唯一的身份标识（用的频率不如 class 高）。

**src="..." / href="..."：**

- 告诉元素去哪里加载资源或跳转（例如图片标签 <img src="a.jpg" />）。

#### 4. HTML 在 Vue <template> 里是如何被“增强”的？

Vue 的 <template> 写法就是标准 HTML，只是加上了 Vue 的特有语法：
需求--------------------原生HTML--------------------------------Vue <template>写法
动态绑定样式-------------<div class="active">-------------------<div :class="{ active: isOnline }">
绑定点击事件-------------<button onclick="doSomething()">-------<button @click="doSomething">
渲染条件判断-------------手动写 JS修改 DOM-----------------------<div v-if="isOnline">在线</div>
引入自定义组件------------不支持---------------------------------<ModeToggle/>（本质也是个自定义复合盒子）
