# SakuHentai v1.3.0

> 自 v1.2.0 以来，围绕阅读恢复、详情体验、维护查重与下载进行了 Round6~9 多轮打磨，v1.2.0 遗留问题基本收敛，进入稳定期。

## ✨ 新增功能

- 本地优先加载：在线打开已下载画廊自动走本地页图，顶部显示「本地版本」徽章，可一键切回在线（元数据与评论仍在线获取）
- 详情新标签导航 + 智能返回：离线卡片 / 在线窄屏 / 面板详情统一新标签打开，返回按钮智能关闭本标签，或回到来源列表并恢复滚动位置 / 页码
- 阅读进度恢复：详情页「立即阅读」显式携带起始页；历史入口始终续看、非历史入口受「是否从上次阅读位置开始」偏好控制（默认关）
- 在线 token 兜底解析：历史记录持久化 token，旧记录缺失时按 gid 自动解析，在线历史打开详情不再报「画廊 ID 或 Token 参数缺失」
- 默认收藏夹：偏好设置配置后，点「加入收藏」走快捷路径（未收藏→收藏 / 不同夹→切换 / 同夹→取消）
- 跨文件夹版本识别：额外路径无 GID 文件夹按标题在线搜索回填 GID/Token/ParentGID，跨路径识别「新版 / 旧版」
- 失效画廊标记：维护查重 404 直标「已删除」，离线维护页新增「清除移除标记 / 全局重新匹配」入口
- 排行榜对齐 E 站真实数据：重写 toplist 解析，对齐真实条目 / 顺序 / 评分（去除 5.0 兜底）
- 对比界面统一：更新 / 维护双列对比左右统一为在线详情结构，本地无评论时隐藏「评论」tab
- 宽屏点卡自动开小详情：宽屏点击卡片自动打开小详情面板，并优化空态交互
- 下载入口拦截：已下载 / 下载中画廊在各下载入口给出明确提示并拦截
- 取消收藏改 web 弹窗：替换浏览器原生 confirm，风格与全局弹窗统一
- exe 自定义图标：打包脚本自动从 `app.ico` 生成图标资源；集成新图标包并修正 PWA manifest 引用
- 全局主题化滚动条：明暗主题下滚动条颜色 / 宽度统一
- 调度时区统一：更新扫描 / Tag 维护调度时刻由硬编码东八区改为系统本地时区，跨设备「下次预计执行」显示一致

## 📖 使用说明

- 下载 `SakuHentai.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「高级设置」中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「安全」中修改
- NAS / 无界面环境请使用 `SakuHentai.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuHentai.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；数据库结构由启动时自动迁移，无需手动处理
