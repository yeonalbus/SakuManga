Core Features

核心特性

打通「在线发现 → 稳定下载 → 本地整理 → 随时阅读」的完整闭环

🔖

搜刮书签工作台

三列书签卡片墙，支持「追新 / 兴趣 / 续扫」三态标记、自定义备注与锚定画廊封面，并在每日指定时间自动检测搜索页更新。

⚡

进阶下载与 Clash 联动

支持多线程断点续传、优先级抢占与归档下载；可对接本机 Clash / mihomo 控制面，在 429 或下载失败时自动换节点重试并切回原节点以节省 GP。

🔄

线上线下双库联动

顶栏一键切换在线与本地仓库，阅读时本地优先加载；支持读取 ComicInfo.xml / metadata 并通过 GID 联网反查补齐元数据。

🧹

智能化本地库维护

每周自动扫描画廊更新并旧化长期未更条目；支持画廊画质一键升级为归档、父子画廊与名称级疑似重复分组查重及忽略屏蔽。

🎲

XP 词云与偏好抽卡

基于库藏分布与阅读频次生成 XP 词云，联动可调库藏/阅读权重、探索率与采样温度的偏好抽卡卡池，并支持多书架与阅读清单。

📱

沉浸阅读与多端协同

支持长合集章节分段、单页收藏与屏蔽指定语言页；内置多用户三级权限，按账号同步阅读进度，并支持 PWA 添加到手机/平板主屏。

Quick Start

快速部署

提供多架构 Docker 镜像与开箱即用的单文件可执行程序

docker run -d --name sakumanga --restart unless-stopped \
  -p 8081:8081 \
  -v /your/data/dir:/app \
  ghcr.io/yeonalbus/sakumanga:2.3.0
  • 同时支持 linux/amd64 与 linux/arm64（群晖 / 威联通 / 树莓派 / Apple Silicon 可直接运行）。
  • 数据库 manga.db、配置 config.json、data/ 与 logs/ 全部保存在挂载目录，升级只需拉取新标签并重建容器。
# 从 Releases 下载 SakuManga.exe 后直接双击运行
# 默认监听地址：http://127.0.0.1:8081
# 首次启动自动创建管理员账号：admin / admin123
  • 单文件内嵌前端静态资源与后端服务，双击运行后最小化到系统托盘，右键托盘可快速「打开界面 / 退出程序」。
  • 如需局域网或手机访问，可在「设置 → 账户 → 服务器」将监听地址调整为 0.0.0.0。
SakuManga.exe --headless
  • 不创建系统托盘图标，适合 Windows Server、无图形界面的服务器或后台常驻服务。
Operations & Safety

运维与安全提示

长期自托管部署前的关键注意事项与完整文档入口

🗄️ 数据备份与平滑升级

  • 数据库结构在启动时通过 AutoMigrate 自动平滑迁移，跨版本升级通常只需替换二进制或更新 Docker 镜像。
  • 大版本升级前建议先备份 manga.db 与 config.json；本地漫画文件建议通过独立卷挂载。

🔐 凭据安全与站点风控

  • 首次登录后请立即修改默认管理员密码 admin / admin123；公网暴露请前置反向代理与 HTTPS。
  • 程序强依赖 E-Hentai / ExHentai 站点可用性、代理配置与账号配额，建议合理控制并发线程，避免触发 429 或 IP 配额耗尽。
