> 自 v1.4.0 以来，围绕本地书库维护做了系统增强：名称级疑似重复自动分组（只建议、不自动处理）、可恢复的忽略标记、维护页交互重构，并显著降低大规模书库的在线核对耗时。

## ✨ 新增功能

- **名称级疑似重复分组（O3）**：维护查重新增「疑似重复」区——按「核心名 + 画师 + 卷号」自动聚类多语言版本 / 重传补档 / 版本变体（重绘、新装版等），高置信 / 中置信两档标注；**只出建议，不自动删除，设置里也无自动处理开关**。
  - 智能清洗：剥离展会届数（C94）、DL 版、汉化组名、语言后缀等版本标记；卷号（Vol.2 / 第3話 / 後編 / 总集篇）提取为独立特征，续集 / 分卷天然隔离不误判；罗马数字、全角、大小写归一。
  - 画师辅助判定：从 E 站 `artist:xxx` 标签提取（标准化可靠），同画师 + 同核心名 + 页数差 ≤5 判定为高置信；撞名不同画师不聚组。
- **忽略标记（O2）**：疑似重复组与父画廊更新提示支持一键忽略，忽略后增量查重不再提示，全量核对仍会列出（带「已忽略」标记、可单独解除）；维护页「🕶️ 忽略清单」弹层可随时查看 / 恢复全部忽略条目，恢复后下次查重重新参与。
  - 忽略按「核心名 + 画师」（title 型）与「父画廊 gid」（gid 型）记录；title 型天然覆盖同作品的全部变体（含未来出现的同名新画廊）。
- **维护页 UI 重构**：按钮区重排（🔍 重新扫描为主按钮）、新增统计条（建议删除 / 疑似重复组 / 已忽略 / 建议保留）、疑似重复簇卡片（成员横排：封面 / 标题 / 语言 / 页数 / 画师）。
- **簇双列对比**（Round26-2）：点击「⇄ 查看对比」进入双列对比页，左/右窗口各有标签卡（A/B/C…）可**独立切换**组内任意两本（如左=第一本右=第三本）。
- **成员级忽略**（Round26-2）：「忽略本组」弹层支持选择**部分成员**忽略（误判剔除，该漫画不再参与疑似判定；剩余 ≥2 本组保留、<2 本组消失），或整组忽略。

## 🛠️ 优化改进

- **E 站请求自适应限流**：固定 1.2s 限流改为自适应——连续成功自动提速至 500ms（约 2 req/s），429 / 503 / 网络失败自动退避（×2 至 5s），全量在线核对耗时约减半。
- **维护页进入不再自动扫描**：检测到书库变更仅提示「结果已过期」，由用户手动点「重新扫描」，避免每次进入页面意外触发数十分钟的全量联网核对。
- **规则 3（父画廊）忽略支持**：用户故意保留旧版（如完整版 / 日文原版）时，可忽略「旧版可删除」提示。

## ⚠️ 已知问题

- **跨语言翻译标题不聚类**：日文原版与英文意译标题（字符层面无关，如 `サンプルタイトル` vs `Sample Title`）无法由名称级判定可靠聚组，属设计取舍（宁漏不误）；保留原名的 `(English)` 后缀变体可正常聚类。
- **性能项 B/C 暂缓**：详情请求跨任务缓存复用（数据陈旧风险）、核对窗口化（频繁增量场景反而更慢）两项未实施，决策 C1/C2 记录于 `plans/round26-o2-o3-dedup-refine-plan.md`。

- **性能项 B/C 暂缓**（见上），珱垣已确认可接受（真实库扫描 3~5 分钟）。

## 📖 使用说明

- 下载 `SakuHentai.exe` 后双击即可运行，默认监听端口 `8081`，首次启动自动创建管理员账号 `admin` / `admin123`（请登录后修改密码）。
- NAS / 无界面环境请使用 `SakuHentai.exe --headless`。
- 升级安装：直接替换 `SakuHentai.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留；新增 `ignored_identifiers` 表由启动时 AutoMigrate 自动创建，无需手动操作。
- 手工开发提示：修改前端后需 `npm run build` 并同步产物到 `backend/webui/dist`（`build-release.bat` 已内置该步骤）。
