## 二、代码修复：系统代理自动兜底（本次已实施）

**根因**：SakuManga 后端只认 `config.json` 手动配置的代理；而 Clash / v2rayN 的「系统代理」模式写入的是 **Windows 注册表**（`HKCU\...\Internet Settings` 的 `ProxyEnable` / `ProxyServer`），Chrome/Edge 会自动读取，但 Go 后端不读 → 浏览器能上 E 站，程序连不上。

**修复**：
- 后端新增 `DetectSystemProxy()`：手动未配置时自动探测「注册表系统代理 → 环境变量 http(s)_proxy」
- 传输层改用 `GetEffectiveProxy()`（手动优先、系统兜底），E 站请求与标签引擎（GitHub 下载）都生效
- 设置页「网络」显示当前生效代理与来源（手动配置 / 自动跟随系统代理 / 直连）
- 附带：配置代理时留空 = 自动跟随系统代理（不再强制直连）

**验证**：本机实测探测到 `http://127.0.0.1:7897`（Clash 系统代理）；单测覆盖 `normalizeProxyServer` 全部注册表格式；后端全量测试 + 前端 type-check 通过。

**效果**：群友那种「Clash 开了系统代理、exh 浏览器能开」的场景，**升级后零配置直接能连**。

## 三、答疑话术（可直接复制回复群友）

### 3.1 代理连不上（对应旧版本，新版已自动修复）

> 新版已修复：开了系统代理（Clash）现在会自动跟随，不用手动填了。等新版本出来替换 exe 即可。
> 如果还连不上，去「设置 → E 站连接 → 网络」填一下代理地址，就是你 Clash 首页显示的那个端口，一般长这样：`http://127.0.0.1:7897`。留空表示自动跟随系统代理。

### 3.2 Chrome 弹「检查已保存的所有密码」

> 这个不是软件问题，是 Chrome 的安全提醒：你把软件的默认账号密码（admin/admin123）存进了 Chrome 密码管理器，Chrome 发现这个密码在公开泄露库里就提醒你改。
> 解决：登录后去「设置 → 账户」把默认密码改掉，然后在 Chrome 里删掉这条保存的密码（或忽略提醒）就行。

### 3.3 不知道访问什么 / 默认账号

> 双击 SakuManga.exe 后，浏览器打开 http://127.0.0.1:8081（程序会自动拉起浏览器）。首次启动账号是 admin，密码 admin123，登录后建议去「设置 → 账户」改掉。

### 3.4 cookie 重填麻烦

> cookie 不用逐条填！在「绑定 Cookie 凭证」弹窗里有个「快速粘贴整条 Cookie」输入框，把浏览器里复制的完整 cookie 字符串（形如 ipb_member_id=xxx; ipb_pass_hash=xxx; igneous=xxx; sk=xxx）整条粘进去，会自动拆开填好。另外「刷新凭证」按钮可以自动更新 igneous（里站）和 sk，不用自己上站抓。

## 四、ehv 对比卖点素材（供推广文案使用）

| 维度 | ehv（E-Hentai Viewer） | SakuManga |
|------|------------------------|-----------|
| 形态 | 单机客户端 / 移动端 | Web 界面，浏览器打开即用，可 PWA 装到手机主屏 |
| 部署 | 每台设备单独装、数据分散 | 一个 exe 集中托管，手机/平板/PC 随时随地访问同一书库 |
| 多语言画廊 | 整本下载，语言混杂 | 可屏蔽其他语言，只显示中文 |
| 合订本 | 几百页一页页翻 | 自动分章节（目录/大纲），跳转阅读 |
| 父子画廊更新 | 无法及时跟踪，重复下载 | 本地父子关系自动追踪，更新替换不重复占盘 |
| 文件查重 | 无 | 文件名 + gid 双重查重，疑似重复自动分组 |
| 筛选 | 基础 | 正/负向 Tag 组合过滤（本地遵循线上语法）、随机抽卡 |
| 搜刮 | 手动记录 | 书签一键回场（保存搜索条件 + 锚定卡片） |
| 整理 | 文件夹手工分类 | 本地书架分类 + 批量移出 + 画质升级（画廊版→归档原图） |
| 多用户 | 单人 | 管理员/成员/下载三级权限，阅读进度云端同步 |
| 运行环境 | 桌面/移动设备 | Windows 双击即用 / NAS 无头模式（--headless） |

**一句话卖点**：ehv 适合单机随手看，SakuManga 适合「囤」——下载、整理、查重、升级画质、多端同步一条龙。
