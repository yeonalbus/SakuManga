在 Vue 项目中增加一个新的页面视图，逻辑非常固定，遵循 **“新建文件 -> 注册路由 -> 加导航入口”** 固定的三步流程。

以在线模式新增一个“热门”页面（路径定为 `/online/hot`）为例，需要依次操作以下三个地方：

---

### 第一步：创建对应的视图文件（Views）

在 `src/views/online/` 目录下新建一个名为 `OnlineHot.vue` 的文件：

**文件路径：** `src/views/online/OnlineHot.vue`

```vue
<template>
  <div>
    <h1>🔥 热门</h1>
  </div>
</template>

<script setup lang="ts">
// 暂时不需要逻辑，先留空
</script>
```

---

### 第二步：在路由表里注册这个新页面（Router）

打开路由配置文件，告诉 Vue Router：“当用户访问 `/online/hot` 这个网址时，去调取刚才创建的 `OnlineHot.vue` 界面”。

**文件路径：** `src/router/index.ts`

在 `routes` 数组里追加一条新记录：

```typescript
const routes: RouteRecordRaw[] = [
  {
    path: '/',
    redirect: '/online/home',
  },
  {
    path: '/online/home',
    name: 'OnlineHome',
    component: () => import('@/views/online/OnlineHome.vue'),
  },
  {
    path: '/online/favorites',
    name: 'OnlineFavorites',
    component: () => import('@/views/online/OnlineFavorites.vue'),
  },
  // ─── 新增这一段 ──────────────────────────────
  {
    path: '/online/hot',
    name: 'OnlineHot',
    component: () => import('@/views/online/OnlineHot.vue'),
  },
  // ───────────────────────────────────────────
  {
    path: '/offline/home',
    name: 'OfflineHome',
    component: () => import('@/views/offline/OfflineHome.vue'),
  },
  // ... 其他已有路由
]
```

---

### 第三步：在侧边栏加上点击入口（Menu）

最后在导航栏里加一个 `<router-link>` 按钮，这样用户才能点击跳转过去。

**文件路径：** `App.vue`（或者你抽取出来的 `OnlineSidebar.vue`）

在“在线模式”的导航组里加一行：

```html
<div class="nav-group">
  <span class="group-title">🌐 在线模式</span>
  <router-link to="/online/home">首页</router-link>
  <!-- 新增这行链接 -->
  <router-link to="/online/hot">热门</router-link>
  <router-link to="/online/favorites">我的收藏</router-link>
</div>
```

---

### 总结三者的配合关系

- **`OnlineHot.vue`**：负责准备好**页面内容**。
- **`router/index.ts`**：给这个页面分配一个**网址（Path）**。
- **`<router-link>`**：在界面上做一个**可以点击的按钮**，引导用户访问那个网址。

只要以后想加新页面，按这三步走就不会遗漏环节。
