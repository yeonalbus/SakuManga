AI 调研出的关键事实（与方案原文有出入，逐条与珱垣确认）：

| 事实 | 结论 |

| 线上库 `Y:\SakuManga\manga.db`（只读）：7778 本离线漫画、`rating` **全为 0**、老化 2743 本、父链已核对 7439 本 | 评分从未被任何流程写入过；需要回填 |

| 「强制全量在线核对」3a 段对 `AgedStatus`/`RemovedStatus` **硬跳过** | 老化本拿不到评分（后来演变成 A 方案讨论） |

| 决策标签实际 4 个（渣翻/外部广告/马赛克修正/无修正） | 与方案写的 3 个不一致，需对齐 |

### 二、决策清单（均经珱垣拍板）

1. **评分字段新增、不复用 `rating`**：避免「用户评分 / 社区评分」混用；新增 `community_rating`。
2. **回填不加独立任务**，走现有两套入口；后追加 A 方案：`强制全量在线核对` 放开老化跳过（`(c.AgedStatus && !forceFull) || c.RemovedStatus`），一次约 2.6 小时覆盖全部 7778 本。
3. **缩略图**：新增 `/comics/:id/page-thumb/:index`（240px JPEG + `page_cache/` 缓存 + 单飞锁 + 解码信号量 2 + ETag）；点开**直出原图**（复用 `/raw-page`，不缩放）。
4. **展开区**：不改外框（diffline → 两栏 panel → 移除按钮），panel 内换成缩略图墙，**固定 320px 高 + 64px 缩略图 + 栏内滚动条**，初始 12 张、滚到底 +6、到底显示「已全部加载」。长本（2000+ 页）只滚不撑长页面。
5. **禁止页码对齐**：不做 A/B 同页并排；切换按「最近打开的两本」来回跳，各回各的最后一页。
6. **评分展示**：不用胶囊、纯文字（`★ 4.31` / `★ —`），两位小数、等宽数字；缺失时灰色破折号。
7. **卡片布局**：标题固定 2 行（单行也占两行高度）；封面固定 3:4（120×160，和书签卡同规格）；决策标签顺序固定为 马赛克修正 → 无修正 → 渣翻 → 外部广告，不占空位、紧贴评分。
8. **成员卡固定 2 列 n 行**（3 本时 `A B` / `C` 空位，不拉伸）；展开区顶部改成 `‹ [A] B C ›` 成员切换条（最多显示 5 个、超出横向拖、点箭头或点字母切换，左右不允许同一本）。
9. **范围**：紧凑视图、独立对比页、本地详情页评分、忽略清单页均不改。

### 三、踩坑记录（评分胶囊那段，最费周折）

- 第 1 轮：`★ -` 比 `★ 4.31` 短一截 → 珱垣要「组件视觉一致、按 x.xx 占位」。
- 第 2~4 轮：试过 `★ -.--`、隐形 `0.00` 占位、伪元素撑宽、绝对定位居中；珱垣逐轮指出「右边空一大块」「星被放最左端」「内容视觉不一致」。
- 视觉分析（放大截图量出：基准 star 58×57、gap 25px、数值 142×63；短横只有 23×6）证明：**短横的视觉重量不足**是「看起来差东西」的根因之一，gap 又因用空格当间距比基准多了 8px。
- 最终结论（珱垣）：**放弃黄色胶囊，改纯文字**——没有背景框就不存在「框内空一块」，星与值恒定同构。这一轮之后才收口。
