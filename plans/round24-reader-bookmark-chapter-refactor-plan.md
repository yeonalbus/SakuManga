> 状态：设计稿（仅方案，不含实现代码）。关键词已由珱垣决策，细节默认值可再调。
> 目标版本：继 v1.4.0 之后的升级轮。
> 设计日期：2026-08-26

## 一、背景与目标

- **现状缺陷（Bug）**：Round23 引入的「自定义删除页面（隐藏页软删除）」在 `OfflineDetail.vue` 预览面板的「管理模式」里可以正确隐藏/恢复页面，但**阅读器打开后没有正确同步隐藏结果**。已定位成因：阅读器与普通预览用「有效序号」图 URL（`/page/:有效序号`）加载，且该 URL 被后端强缓存（`Cache-Control: public, max-age=86400`）；隐藏页变化后，**同一个「有效序号」会指向不同的物理图，但浏览器仍命中旧缓存** → 阅读器显示被隐藏/错位的旧图，而管理模式预览用 `/raw-page/:物理索引`（物理索引稳定）显示正确。

- **本设计目标**：
  1. 修复隐藏页在阅读器不同步的 Bug。
  2. 把整条阅读/预览链路从「有效序号」模型重构为「**物理索引**」锚点模型（这是后续书签/章节/范围排除的地基）。
  3. 新增**本地**书签标记与章节标记（章节 ≤ 3 级、可命名）。
  4. 新增「范围内排除」（如 P1-P30 整段隐藏，适配多语言版画廊快速隐藏非目标语言）。
  5. UI 参考笔记类 App 引入「侧栏抽屉 + 多视图 Tab（缩略图网格 / 章节大纲 / 书签）」，但**横屏与窄屏均折叠成抽屉**，保证阅读沉浸感。

## 三、核心模型重构：以「物理索引」为唯一锚点

### 3.1 当前模型（问题）
- 页序用「有效序号」：隐藏页后，后续页有效序号整体前移；
- 任何「绑定某一页」的实体（书签/章节标记、进度恢复）若绑有效序号，都会随隐藏变化而漂移；
- 图 URL `/page/:有效序号` 命中强缓存 → 隐藏后错位。

### 3.2 目标模型（物理索引锚点）
- 后端 `/pages` 已返回：`total`（有效页数）、`pages`（有效文件名）、`originalTotal`（物理页数）、`hiddenPages`（物理索引数组）。**后端基本不动**。
- 前端在阅读器内自建「**可见物理索引序列**」：
  ```
  visiblePhysicalIndices = [物理索引 0..originalTotal-1] 过滤掉 hiddenPages 中的项
  ```
- `currentPage`（1-based **显示序号**）→ 映射 `visiblePhysicalIndices[currentPage - 1]` 得**物理索引**。
- 图片一律用物理索引加载：`GET /comics/:id/raw-page/:物理索引`（URL 稳定 → 强缓存安全，不再错位）。
- **书签 / 章节标记 / 进度恢复全部绑定「物理索引」**，与隐藏页联动天然一致（隐藏某物理页 → 其标记自动剔除）。

### 3.3 在线模式
- 在线阅读器无隐藏页概念，**保持现有 `/comics/online/pages` 路径不变**，仅离线分支做物理索引重构。

## 四、后端改动设计

> 工作量评估：小。主要复用现有 `raw-page / pages / hidden-pages` 接口，新增标记表与 CRUD，及一处隐藏联动清理。

### 4.1 新增数据表（跟随本地漫画，`comicId = 本地漫画 id (md5)`）

**表 `comic_bookmark`（书签）**
| 字段 | 说明 |
|---|---|
| id | 主键 |
| comic_id | 本地漫画 id（md5），索引 |
| page_index | 物理页索引（0-based） |
| created_at | 创建时间 |

**表 `comic_chapter`（章节标记，树状 ≤3 级）**
| 字段 | 说明 |
|---|---|
| id | 主键 |
| comic_id | 本地漫画 id（md5），索引 |
| parent_id | 父章节 id（0 或 NULL = 一级） |
| level | 1 / 2 / 3 |
| title | 自定义名称 |
| page_index | 起始物理页索引（0-based） |
| order_no | 同层排序号 |
| created_at | 创建时间 |

- **约束**：`level` 只能为 1/2/3；`parent_id` 的 `level` 必须 = 当前 `level - 1`（允许跳级 = 任意 `level` 可直接作为根，或挂在任意低一级父节点下）。
- **章节的「章名」显示**：物理页属于哪个章节 = 最后一个「起始页 ≤ 当前物理页」的章节。

### 4.2 新增/调整接口

| 接口 | 方法 | 说明 |
|---|---|---|
| `/comics/:id/bookmarks` | GET | 返回该书签列表（physicalIndex 数组） |
| `/comics/:id/bookmarks` | PUT | 整体覆盖书签列表（或 POST 单条） |
| `/comics/:id/bookmarks` | DELETE | 删除指定书签（按 physicalIndex） |
| `/comics/:id/chapters` | GET | 返回章节树（含层级/名称/起始物理页/排序） |
| `/comics/:id/chapters` | PUT/POST/DELETE | 增删改章节（单条或整体覆盖） |
| `/comics/:id/pages` | GET | **不改**；前端据此构建可见序列 |
| `/comics/:id/hidden-pages` | PUT | **复用**；联动见 6.2 |

### 4.3 隐藏联动清理（后端原子化）
`UpdateComicHiddenPages` 在更新 `hiddenPages` 时，**一并删除** `comic_bookmark` 与 `comic_chapter` 中 `page_index` 落在新增隐藏集合内的记录（硬删除：标记目的已随页消失）。返回里带上被清理的标记数量以便前端提示。

## 五、前端改动设计

### 5.1 阅读器 `ComicReader.vue`（离线分支物理索引重构）
- 离线加载改为请求 `/comics/:id/pages`，读取 `originalTotal` + `hiddenPages`，构建 `visiblePhysicalIndices`。
- `currentPage` 显示序号 ↔ 物理索引映射；图片加载用 `/comics/:id/raw-page/:物理索引`。
- 进度恢复/保存绑定**物理索引**；旧进度（历史存的有效序号）做兼容回退（见 9.1）。
- 双列模式一屏 = `visiblePhysicalIndices[cp-1]` 与 `[cp]` 两物理页。

### 5.2 侧栏抽屉（新增组件，保沉浸）
- 阅读器内新增可开合**抽屉**（从左侧滑出），含三 Tab：
  1. **缩略图网格**：可见页 + 已隐藏页标注，标记页加角标，当前页高亮。
  2. **章节大纲**：三级树，节点显示「名称 + 起始页」，点击跳转到该物理页所属显示序号；当前所在章节高亮。
  3. **书签**：只列打了书签的页，点击跳页。
- **横屏与窄屏均折叠**为抽屉，默认收起，由顶部按钮/手势唤起，避免遮挡阅读主体。
- 顶部显示当前章节名（`visiblePhysicalIndices[cp-1]` 所属章节）。

### 5.3 标记编辑入口（本地）
- 阅读器内：长按当前物理页 / 页上下文菜单 → 「添加书签」「添加章节标记」。
- 添加章节：打开层级与命名输入（可选 1/2/3 级；选父节点后自动定级）。
- 设置中心「阅读体验」新增开关：`showChapterOutline` / `showBookmarks` / `showHiddenBadge`（默认开）。

### 5.4 管理模式 `OfflineDetail.vue` + 范围排除
- 现有「点选多选 + 隐藏/恢复」保留。
- **新增区间工具**：管理模式工具条加两个数字输入框（起、止，如 `P1`、`P30`）+「加入隐藏 / 移出隐藏」按钮，一键整段框选；支持按住 Shift 点起止缩略图做区间框选。
- 提交仍走现有 `saveHiddenPages`（物理索引列表）。
- 普通预览也用物理索引重构后的 URL，与管理模式一致。

## 六、联动规则

### 6.1 屏蔽 → 标记
- 物理页加入 `hiddenPages` → 该物理页的书签、章节标记**自动删除**（后端原子清理，前端同步刷新侧栏与角标）。
- 物理页从 `hiddenPages` 移除（恢复）→ 不自动重建标记（标记随删除已丢失，需用户重新标记）。

### 6.2 章节嵌套与删除
- 删除某章节节点 → 其**下所有子章节一并删除**（树节点删除）。
- 仅删除章节标记的「名称/起始页」不含子章节，支持编辑。

### 6.3 范围排除与标记
- 一段物理页被整段隐藏 → 其中所有标记一并清除（同 6.1）。

## 九、默认建议 & 待细化项

1. **旧进度兼容（已确认：允许破坏性更新）**：重构后进度绑定物理索引。**历史旧进度作废、阅读进度重新开始**，不做旧「有效序号」的近似还原（隐藏集未知时必然错位，直接作废更干净）。
2. **书签/章节同一物理页共存**：默认允许一书签 + 一章节起始页落在同一物理页（语义不同、不冲突）。
3. **标记编辑入口层次**：默认放长按页 + 设置开关，不新增独立管理页（避免入口过重）。
4. **在线阅读器**：无书签/章节/范围排除，保持现状；仅在离线分支与侧栏做新增。
5. **设置默认值**：三个开关默认开。
6. **章节删除交互**：默认父删连同子树删；如希望「父删子保留、子上提」，后续可调。
7. **上下控制条显隐（已确认）**：主交互为「单击画面切换显隐」——控制条显示时单击画面隐藏、隐藏时单击画面任意处恢复（整个画面为大热区，触屏友好）；翻页触屏用滑动、鼠标用两侧热区/方向键，与单击不冲突；设置中心新增「自动隐藏控制条」开关（默认关）；保留 ✕ 按钮（桌面习惯）。
