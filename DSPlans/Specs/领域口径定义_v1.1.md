# SakuManga 领域口径定义（v1.1）

> **状态**：**全部决策已批准（珱垣，v1.1）**。实施顺序见 §4；每条口径落地为「一个导出函数/常量 + 一条回归测试 + 一条反例测试」。
> **定位**：SakuManga 是第一个正式发行版作品，接受"先定口径、再按拓扑顺序落地、不重写"的路线。
> **事实源**：代码（函数名/常量/测试）= 事实；本文件 = 为什么这么定与影响面。实施中发现定义冲突，先回本文档记录，再改代码。

## 1. 总则

### 1.1 分层与事实源

- 数据事实：`manga.db`（SQLite，AutoMigrate 增量迁移，无破坏性 schema 变更）。
- 契约事实：REST DTO（`handlers/*.go`）+ 前端类型（`src/types/*.ts`）；字段语义以本文件为准。
- 代码事实：口径 = 函数/常量/测试；函数名与测试名必须直接表达定义（如 `isGalleryRootLevel`、`TestNestedArchivesOnlyDirIsNotABook`）。

### 1.2 兼容与迁移原则

1. **默认路径零感知**：对"下载导入 + 平铺目录"用户，2.4.0 的可见行为不变。
2. **不静默删除数据**：涉及存量记录消失（rar/7z 死本子、父子重叠孤儿），一律独立清理工具 + 数量预告，由珱垣确认执行。
3. **ID 不变**：不改变 `md5(LocalPath)` 生成规则；路径规范化只用于比较/去重。
4. **一次一条**：每条口径一个提交 + 测试（含反例），可单独回滚。

## 2. 对象定义

### 2.1 本子（Gallery）

**定义（D1/D2）**：

> 一个本子 = 一条扫描路径下的**一个直接子目录**（其内部任意深度的图片递归构成页表），或扫描路径下的**一个直接归档文件**。
> 扫描路径自身直接含图片时，扫描路径本身是一个本子；其子目录不再单独成为本子。

**单本模式边界（v1.1 补充）**：扫描路径根自身直接含图时，整个根目录进入单本模式——其下子目录与根下归档文件**均不再单独切本**（视为该本子内部的附属文件，归档内的图片不计入页表）。

**建本门槛（D2 新增）**：

> 直接子目录的**递归图片数 = 0 → 不建本**，跳过并计入 `skipped(reason=empty)` 告警；即使该目录内只有 `*.zip` 等归档文件也不建本。

**全局忽略规则（D1 新增）**：

> 扫描遍历（含递归下钻、归档收集、页表列举）一律跳过名称以 `.` 开头的目录与文件，覆盖 `.saku_trash`（D14 删除回收目录）、`.git`、`.stfolder`、`.hidden` 等；该规则对所有扫描模式与下载入库扫描一致生效，防止临时/隐藏目录被重新扫入库。

**使用前提（必须写进 UI 说明）**：

> 扫描路径必须是「单本的父目录」。挂到「作者/社团」这类多级分类总目录时，其**下一层（系列）会被当成一本**，系列内的本子被吞并成一册大杂烩——这是挂载层选错，不是扫描器可自动判断的问题。

**不变量**：

- 任意一张图片只属于一个本子（父子两本同时包含同一张图的情况不存在）。
- 本子页数 = 页表长度 = 阅读器可翻页数。
- 一个扫描路径只切一层：本子的父目录必须就是该扫描路径（或本子就是根/根下归档）。

**边界示例**（`Posted` 为扫描路径）：
```
Posted/20260213露露卡/1st/a.jpg
Posted/20260213露露卡/2nd/b.jpg
→ 1 本：20260213露露卡（页表 = 1st\a.jpg、2nd\b.jpg，2 页）

Posted/某作者合集/vol1.zip      ← 直接子目录内无散图
Posted/某作者合集/vol2.zip
→ 0 本：某作者合集 递归图片数 0，跳过并告警（不建 0 页本）

Posted/20260214附件（散图）/x.jpg   ← 根下直接是子目录且有散图
→ 1 本：20260214附件

<扫描路径根>/cover.zip          ← 根下直接归档
→ 1 本：cover.zip
```

**与现状差异**：现状"最浅层含图目录"会让 `1st/2nd` 各成一本，根自身含图时父子重叠，纯归档子目录又会被建成 0 页本；D1/D2 落地后三者全部消除。

### 2.2 页与索引

**定义（D3/D9/D10）**：

- 页表 = 本子内全部图片的相对路径（自然排序，含子目录，**递归**）。
- **物理索引**是唯一对外索引：`/raw-page/:index`、`/page-thumb/:index`（改物理语义）、阅读进度、书签、章节、灯箱全部使用。
- **有效索引**只在后端计算有效页数、在前端展示"第 k 张/N 张"时由 `physicalIndices[k-1]` 映射得到，不出现在 URL、存储、接口参数中。
- 路由收口：**删除 `GET /comics/:id/page/:index`**（有效索引语义），只保留物理索引路由；同仓库发版，前端同步改造，不保留兼容端点。

### 2.3 隐藏页

**定义（D10）**：`HiddenPages` 存**相对路径数组**（`["001_ad.jpg","sub/cover.jpg"]`，ToSlash 归一），构造有效页时用 `map[string]bool` 匹配。
兼容读取：元素是纯数字时按旧物理索引解析（`0..len-1` 映射为当前页表相对路径），保存时一律写字符串形式。
扫描/更新替换后页面增删不再导致隐藏错位；页名本身变化（重命名图片）时按"找不到即忽略"处理并计入告警。

### 2.4 封面

**定义（D11）**：封面 = 本子页表排序后的第一张**未隐藏**图片，与阅读器第 1 页一致；目录与归档同一规则；封面缓存随隐藏页变化失效。

### 2.5 元数据

**定义（D13）**：查找范围 = 本子根目录（目录形态，不含子目录）或归档内任意深度（归档形态）。
优先级：`ComicInfo.xml` > `metadata` > `ametadata` > `info.json` > `.ehdata` > 其他 `*.json`（仅当以上均不存在时作为兜底，并记录 `metaSource`）。
同名字段先到先得；`tags` 各来源追加后去重（忽略大小写与命名空间前缀差异）。

### 2.6 扫描路径（ExtraScanPath）

**定义（D8/D15/D16）**：

- 一条扫描路径 = 一个书库根，只切一层（D1）。
- **`IncludeSubfolders` 语义（重写，消除二义）**：
  - `true`：按扫描路径的**直接子目录**切本（D1），根自身直接含图时根也成一本，根下直接归档各成一本。
  - `false`：**仅扫描路径根目录自身视为单本**（平铺图 = 一本，页表递归）；根自身递归图片数为 0 → 跳过并告警；根下归档文件**不再单独成本**。此模式专用于以单个本子目录作为扫描入口的场景（下载落地目录即典型用例）。
- `EnableOfflineUpdate` 关闭 = 该路径记录退出「联网维护 + 本地查重」，展示/阅读/删除不受影响。
- 删除路径 = 先清记录（D14 同款两阶段）→ 再删路径行；磁盘文件保留；扫描中拒绝删除；路径不存在时幂等且不按任意 id 删库。

### 2.7 离线记录（OfflineComic）

**定义（D5/D7/D8）**：

- 主键 `ID = md5(LocalPath)`，`LocalPath` 唯一；路径比较规范化（`filepath.Clean` + 统一分隔符 + Windows 下大小写不敏感比较），但已存 ID 与 LocalPath 不改写。
- 改名/移动 = 新记录，旧记录成为孤儿 → 由清理工具识别（同 gid 且路径不存在），不自动删除。
- 全量扫描字段策略见 §2.9（三类互斥白名单）。

### 2.8 维护查重

**定义（D19/D20）**：本地候选 = 全部离线记录（仅排除关闭离线维护的路径）；联网候选 = 本地候选再排除老化/失效。规则 2（归档 hash）与规则 4 一样输出「建议保留」。忽略恢复后立即本地重算（不联网）；忽略匹配以成员集合为准并记录簇键，成员集合变化超过阈值时提示重新确认。

### 2.9 扫描字段白名单（D7，三类互斥，以 Go 字段名为准）

| 类别 | 语义 | 字段（`models.OfflineComic`） |
|---|---|---|
| **Scan-Owned**（无条件覆写） | 扫描可完全决定 | `PageCount`、`OriginalPageCount`、`FileSize`、`FileModifiedAt`、`SourceMode`、`Category`、`UpdatedAt`（仅当被覆写字段确有变化时刷新；**检测类流程不得改写 UpdatedAt**） |
| **Merge / Fill-If-Empty**（条件合并） | 用户/在线值优先，扫描只补空或未手改 | `Title`、`TitleJpn`（`Title != OriginalTitle` 或 `TitleJpn != OriginalTitleJpn` 视为手改，不覆盖）、`GID`、`Token`、`ParentGID`（空值填充，保护在线回填）、`PublishedAt`（空值填充）、`CommunityRating`（库中为 0 才写）、`OnlineTags`（**仅当为空时**用本地侧车元数据标签填充，非空一律只读）、`Tags`（由 `OnlineTags + OfflineAddTags − OfflineRemoveTags` 合成；**不直写三态源字段**） |
| **Scan-Protected**（扫描只读） | 扫描一律不写 | `ID`、`LocalPath`、`Source`、`CoverURL`、`IsDownloaded`、`Rating`、`ClickCount`、`ReadCount`、`NeedsUpdate`、`NewGID`、`NewToken`、`UpdateNote`、`AgedStatus`、`AgedCheckedAt`、`RemovedStatus`、`RemovedAt`、`ParentCheckedAt`、`FileHash`、`SigDirMtime`、`SigComputedAt`、`DownloadScheme`、`OriginalTitle`、`OriginalTitleJpn`、`Remark`、`HiddenPages`、`AddedAt`、`ScanPathID`、`OfflineAddTags`、`OfflineRemoveTags`、`LastTagRefreshAt`、`TagRefreshCount` |

实现约束：三类各由一个函数表达（`applyScanOwned` / `mergeScanFields` / 保留即"不赋值"），禁止再用 `DB.Save(整行)` 落库；改用 `Updates(map)` 只写显式属于 Scan-Owned / Merge 的列。

### 2.10 来源（D8/D15）

- `ScanPathID` 空 → 可写为路径 ID（首次来源）。
- 路径 ID → 空：**不写**（下载目录被设为扫描路径时不改来源）。
- 路径 A → 路径 B：**不改写**（来源不可变）；因路径被删除/重建导致的来源失效，由「已移除来源」标签兜底。
- 来源标签：路径存在 → 路径 `Name`；路径已删/`Name` 空 → 「已移除来源」；下载导入 → 「下载」。详情接口必须返回 `sourceLabel`。

### 2.11 删除（D14，两阶段原子重命名）

适用于单本删除、批量删除、删除扫描路径下的记录。

1. 校验记录存在；计算同 gid 引用/评分迁移目标。
2. **寻位**：目标路径同盘回收目录 `<文件所在目录>/.saku_trash/<comicID>-<unixms>/`（保证 Rename 跨目录同盘原子）。
3. **第一阶段（文件）**：`os.Rename(LocalPath, 回收目录)`。Windows 下文件被占用会在此报错 → `tx.Rollback()`，返回错误，DB 与文件均未变。
4. **第二阶段（数据）**：事务内删除记录、迁移或清理引用（历史/书架 `comicIds`+`sortKeys`+`coverComicId`/阅读清单）、迁移或删除 `ComicRating`、删除 `ComicBookmark`/`ComicChapter`；`Commit`。Commit 失败 → 尝试把回收目录 Rename 回原路径（回滚）；回滚再失败则记录告警，交由启动期回滚工具处理（DB 记录仍在，可重试）。
5. **收尾（允许失败）**：`os.RemoveAll(回收目录)`、删除 `cover_cache/<id>.jpg`、`XpRecomposeComic`、`MarkLibraryChanged`；失败只留垃圾文件，不影响一致性，由启动期 `/temp` 清理兜底。
6. `deleteFile=false`：跳过 2-3 步，仅执行 4-5（不动磁盘）。

## 3. 决策理由（摘要）

- **D1/D2 一层 + 递归**：`1st/2nd` 属于同一本的库形态无法用"叶子目录"表达；"一层 + 递归"把配置动作收敛为"挂载点选对"，且天然消除父子重叠与 0 页空本。
- **D3 递归页数**：页数是更新检测、查重、隐藏页、进度的共同基础。
- **D4 拒绝 rar/7z**：当前无解压实现，识别即造死记录；引入重型依赖与收口维护期不符。
- **D5 不改 ID**：迁移引用风险与收益不成比例；孤儿清理工具足够。
- **D7 三类互斥**：`Save` 全列覆盖是当前最大数据损失源；三类清单可直接对照实现与测试。
- **D9/D10 物理索引 + 相对路径隐藏**：双轨索引是状态错位根源；相对路径让增补替换不再错位，且读旧数据可兼容。
- **D11 封面 = 首页**：封面与第一页不一致会被用户当作排序错误。
- **D14 两阶段重命名**：Windows 文件占用必须能在"改 DB 之前"被拦截；Rename 同盘原子且回滚秒级。
- **D21 入库失败即任务失败**：消灭"下载完成但库里没有"的困惑。

## 5. 存量数据迁移与回滚

- **页数**：阶段一完成后做一次全量扫描重算（D7 保证不丢状态位）。
- **隐藏页**：读时兼容旧纯数字索引，保存时写相对路径；无强制迁移步骤。
- **rar/7z 死记录 / 父子重叠孤儿**：清理工具（复用 `cleanup_orphan_scanpaths` 模式）统计 → 珱垣确认 → 执行。

- **回滚**：每条一提交；涉及库操作前备份 `manga.db`（线上操作遵守既有红线：停服、备份、确认后执行）。
