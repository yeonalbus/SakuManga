# SakuManga v2.0.1

> 自 v2.0.0（2026-08-29）以来共 2 个提交，本版为**首次反馈收敛版**：修复「开启系统代理仍连不上 E 站」的零配置痛点（自动跟随系统代理），落地卡片语言角标与 3TAG 精选、E 站账号密码内部登录（免 F12 复制 Cookie），并修复搜索历史点击直接跳转的交互问题。数据库结构无变化，升级仅需替换 exe。

## ✨ 新增功能

- **系统代理自动兜底**：未手动配置代理时，自动探测并跟随 Windows 系统代理（注册表）或环境变量 `http(s)_proxy`——Clash / v2rayN 等开启「系统代理」模式后**零配置直连**，不再出现「浏览器能上 E 站、程序连不上」；E 站请求与标签引擎（GitHub 数据下载）均生效
- **E 站账号密码内部登录**：绑定/更新凭证弹窗新增「方式一：使用 E 站账号密码登录」——输入账号密码即可完成登录并自动抓取 igneous（里站）/ sk 凭证，**无需再打开浏览器 F12 复制 Cookie**；遇验证码 / 风控时返回明确提示，可回退「方式二：粘贴 Cookie」
- **卡片语言角标**：卡片来源角标（在线/本地）替换为语言标签——从 `language:xxx` 提取并映射为中文 / 日本語 / English 等 15 种常见语言；无语言标签时回退显示来源
- **3TAG 显示优化**：卡片标签区最多展示 3 个精选 tag——parody、character 各取一个（缺失该类不占位），空余槽位用 female 补齐（可多个），female 也没有则不显示；排序固定为 parody → character → female

## 🛠️ 优化改进

- **搜索历史点击行为**：点击历史项改为「填入搜索框」（保持焦点，回车才触发搜索），不再直接跳转搜索，方便在历史词基础上继续编辑
- **网络设置可视化**：设置 → 网络 显示当前生效代理与来源（手动配置 / 自动跟随系统代理 / 直连），直连时给出排查提示；配置弹窗留空语义由「直连」改为「自动跟随系统代理」

## 🐛 Bug 修复

- **开启全局代理（系统代理）后连不上 E 站**：后端此前只认手动配置的代理，不读 Windows 注册表系统代理，导致 Clash 等「系统代理」模式下浏览器可访问、程序无法联网——现自动兜底跟随系统代理

## ⚠️ 已知问题

- 在线热门页（/online/hot）为固定全站热门，不响应筛选抽屉的条件（设计如此；首页 / 订阅页筛选正常）
- E 站账号密码登录受 E 站验证码 / 风控影响可能失败，此时请改用浏览器登录后粘贴 Cookie
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuManga.exe` 后双击即可运行（单文件内嵌前后端 + 自定义图标），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「网络」设置中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「账户」中修改
- 代理配置：开启 Clash / v2rayN 等「系统代理」后无需手动填写，程序自动跟随；如需固定代理地址，在「设置 → E 站连接 → 网络」填写（如 `http://127.0.0.1:7897`），留空 = 自动跟随系统代理
- NAS / 无界面环境请使用 `SakuManga.exe --headless` 纯后端运行
- 升级安装：直接替换 `SakuManga.exe` 即可，`manga.db` / `data/` / `config.json` 跟随 exe 目录自动保留，无需手动处理
