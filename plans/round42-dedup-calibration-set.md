# Round42 查重标定集（候选对照表 · 待抽查确认）

> 用途：为 Round42「离线查重算法升级」提供**召回 / 误报的标定与回归基线**。
> 数据源：云端生产库快照，维护候选集 **3575 本**（`source=offline` 且未老化、未移除）。
> 生成方式：脚本按规则自动构造候选对，**尚未经人工确认**。判定用三层归一（原始 / 剥版本标记 / 去全部括注），
> 已剥净的标记包括：`(C99)` 等展会期号、`[DL版]`、`[無修正]`、`[中国翻訳]`、`[Digital]`、汉化组名等。

## 怎么抽查（尽量省你时间）

1. 主要看「建议」「置信」「差异点」三列。
2. **只需回复判错的行号**（例：`判错：#7 #19 #23`），其余默认视为正确。
3. 行号带 **⚑** 的是边界案例，最需要你判断；不带 ⚑ 的是高置信行，可快速扫过。
4. 拿不准的写「待定」，我按低置信处理。
