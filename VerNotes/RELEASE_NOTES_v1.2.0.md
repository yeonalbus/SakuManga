# SakuHentai v1.2.0

> 自 v1.1.0 以来，围绕在线浏览、下载、维护与多用户体验进行了多轮迭代，v1.1.0 遗留的 4 项已知问题已全部解决。

## ✨ 新增功能

- 阅读进度续看：进度按账号同步后端，换设备 / 切换账号后可继续阅读
- 负向排除筛选：`- tag`（如 `- female:stockings`）与 `- 关键词` 排除（离线过滤 + 在线本地丢弃 + 抽卡同步支持）
- Tag 联想补全：筛选抽屉与抽卡输入框支持标签联想，负向候选以「排除」标注
- 排行榜补全年月：新增 All-Time / Past Year / Past Month 榜单（原仅有昨日）
- 离线双列对比视图：更新 / 维护项一键对比「本地 vs 在线」「保留 vs 删除」
- 每周自动更新扫描：固定时刻自动检测新版本，365 天老化规则自动排除老画廊
- 日志系统：更新 / 维护 / 下载 / 前端错误四类日志，支持查询与实时尾随
- 下载优先级 + 抢占式调度：高优先级任务自动插队，可抢占低优先级
- 归档并发数控制：可限制同时下载的归档数量，多归档并行下载
- 批量下载：长按多选一键加入批量下载
- 日期跳页：订阅页与离线首页可按日期快速跳转
- 下载完成自动消除更新标记、下载后自动比对数据库（去重 / 回写父画廊 / 校正页数）

## 🛠️ 优化改进

- 设置中心重组为 8 大分组，接入 E 站 Profile 与「我的标签」
- 归档下载分块多线程优化，单文件下载速度大幅提升
- 全局下载并发门控，避免多任务并发超线程触发 404
- 下载完成后自动消除更新列表中的更新标记
- 离线首页与历史记录翻页后自动回到顶部
- 维护结果增加时效性校验，跨设备不再展示陈旧缓存

## 🐛 Bug 修复

- 修复历史记录无法续看（进度丢失）
- 修复归档下载多线程并发同一画廊时串行 / 单线程
- 修复订阅页错误显示首页内容
- 修复删除已不存在的记录时报「文件或记录不存在」（改为已删除处理）
- 修复维护 / 更新列表跨端结果不一致（幽灵文件）
- 修复画廊被删与网络故障无法区分，被删画廊重复联网检测

## ⚠️ 已知问题

- 在线列表负向排除为「本地丢弃」，命中条目较多时单页显示条数变少（游标继续加载）
- 抽卡负向排除后候选数量不足时仅提示，后端采样补位为后续增强
- 项目仍处于快速迭代期，可能存在未覆盖的边缘场景

## 📖 使用说明

- 下载 `SakuHentai.exe` 后双击即可运行（单文件内嵌前后端），运行后最小化到系统托盘
- 默认监听端口 `8081`，可在「高级设置」中修改；端口被占用时自动切换空闲端口
- 首次启动自动创建管理员账号 `admin` / `admin123`，登录后请尽快在「安全」中修改
- NAS / 无界面环境请使用 `SakuHentai.exe --headless` 纯后端运行
