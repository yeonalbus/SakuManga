## 正文

### 开场

在座各位应该都有这个体验：本地囤了几百上千本，真到想找某一本的时候，全乱套。

主流管理器各有各的坑：

- **Calibre / Komga / Kavita**：只做本地管理，不能联网更新，对文件命名和格式要求严格；
- **EHentaiViewer（Ehv）**：本地画廊管理弱，服务器 / NAS 场景基本抓瞎；
- **Suwayomi / LANraragi**：Web 方案，但 UI 比较简陋。

**SakuManga** 是另一条路：一个单文件 exe，浏览器打开即用，把「资源刮削 → 本地存储 → 高质感阅读」整个闭环打通。

### 核心卖点（与现有工具的差异点）

1. **搜刮书签**：搜刮到一半有事要走？把当前位置存成书签——自动快照全部筛选状态，还能锚定一张画廊卡片。不用自己记看到哪了。

2. **正负向筛选**：支持正向 + 负向组合过滤（如 `-female:yuri` 排除百合、`-male` 排除含男本），**Ehv 的筛选基本只能正向**；筛选语法与 E 站原版 f_search 一致，本地离线库和在线搜索结果语义完全统一。

3. **阅读清单**：融合管理器的「清单」，适合系列漫画，支持从本地书架一键导入。

4. **书架分类**：本地书架管理 + 与阅读清单联动，系列 / 配菜一键归类，多选批量移出。

5. **画质升级**：SakuManga 自己下载的画廊版（低清）可一键升级为**归档原图版**——自动检测 + 原子替换，历史 / 书架 / 评分全保留，防止「画廊版 + 归档版」重复堆积占盘。

6. **手柄适配**：支持手柄翻页 / 确认 / 取消

7. **高级阅读器**：物理页索引、章节配置、页面收藏（书签）、章节目录快速定位——合订本不用几百页一页页翻。

8. **父子画廊自动追踪**：定时联网核对画廊衍生关系，新版本 / 汉化上线自动提示，不用再手动盯着更新。

9. **智能查重与元数据补全**：GID 精确查重 + 多维度模糊查重；挂载路径导入自带 ComicInfo.xml 的本子，自动联网补全缺失标签与详情。

### 阅读与多端

配了内网穿透 / 服务器之后：阅读器书签与章节侧栏、PWA 装到手机主屏、阅读进度云端同步，人在外面也能随手翻。

### 部署

单 exe 双击即用（Windows），NAS / 小主机用 `--headless` 纯后端模式；
默认账号 `admin` / `admin123`（登录后建议改掉）。
