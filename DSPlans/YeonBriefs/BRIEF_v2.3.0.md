## 三、用户可感知亮点

### A. 搜刮书签（重做）

- **书签升级为独立页面**（侧栏「书签」组标题点击即进）：三列卡片墙，每张卡固定四区——封面 / 标题 / 标记徽章 / 备注框，卡片高度统一。
- **书签标记三分**：追新（蓝）/ 续扫（绿）/ 兴趣（灰），卡片左侧竖色条区分；老书签按原名称自动识别回填。
- **每日自动更新探测**：对开启「更新探测」的书签，每天在设置的刷新时刻各查一页列表，发现比锚点更新的画廊即亮红点；页面顶部另有「检查更新」手动触发。
- **侧栏书签组重做**：不再折叠，常驻「更新探测」按钮 + 最多 **5 条置顶**书签；点击置顶项沿用原「跳转 + 恢复筛选 + 脉冲定位」链路。
- **书签可写备注**（3 行输入框，按折算显示行数校验）、**可置顶到侧栏**、**可标记「已囤货」**。
- **「失效检测 / 清理失效」退场**：不再逐个书签联网验证失效并打标；改为锚点找不回时**按发布时间自动迁移并续定位**（少一次打扰，多一次自动修复）。

### B. 下载链路

- **排队任务不再卡死**：批量加入 700+ 任务时，原容量 256 的待执行通道满即丢弃，任务永久停在「排队中」；现改为**无界待调度队列 + 统一调度器**，任何排队任务必达调度器（实机 704 任务卡死问题修复）。
- **等待并发窗口不再占死执行协程**：等归档并发窗口 / 全局线程配额的任务留在队列，不再占住 worker。
- **普通下载归档失败不再静默降级为画廊**：失败一律报错可重试，落地画质不再被悄悄降级；自动更新任务仍保留开关控制的降级。
- **网络抖动不再固化为降级**：H@H 下载页请求失败先退避重试 2 次（1s / 3s）。
- **下载列表批量操作**：7 个状态页签（带数量）+ 模式筛选，支持**全部取消 / 暂停 / 恢复 / 解锁 / 重试**；跨分页作用于当前筛选结果；超过 20 条才二次确认，「全部取消」始终确认（含损坏压缩包警告）。
- **高级代理设置（管理员）**：可对接本机 Clash / mihomo 控制面，按站点指定代理组；归档下载失败时自动换节点重试（全组延迟排序、过滤假节点、切换后重置连接池），重试时切回原节点以**省 GP 重复扣费**。
- **任务卡显示所用节点名**；代理 Secret 只写不回传（保存后仍显示掩码）。

### C. 界面与图标

- **全站约 550 处 emoji 与字符符号替换为 Phosphor 矢量图标**（`✕ ‹ › ❯ ▲▼ ⠿ « »` 等）：普通位置用空心，收藏 / 书签 / 已下载 / 更新 / 置顶等**状态激活时变实心并沿用状态色**；跨平台渲染一致，不再受系统 emoji 字体影响。

### D. 其它修复

- **订阅页请求路径修正**：改为 `/watched`，请求异常时不再静默退回首页。
- **E-H tag 别名后缀脏数据自愈**：标签解析只取规范 key，历史脏数据自动清理。
- 网络设置保存密钥后仍保留掩码，测试连接自动沿用已保存密钥。
- 维护查重 / 推荐相关单测消除随机性偶发失败（工程侧）。

## 四、升级注意

- 直接替换 `SakuManga.exe`；Docker 用 `ghcr.io/yeonalbus/sakumanga:2.3.0`（或 `:2.3` / `:latest`）。
- 数据库自动迁移，另有一次书签字段回填（幂等）；**建议升级前备份 `manga.db`**。
- 新增管理员设置项「高级代理」，**默认关闭**，不开启不影响任何既有功能。
- 高级代理依赖本机运行 Clash / mihomo 的控制面（默认 `127.0.0.1:9090` 一类），不提供内置代理。

## 五、已知问题（如实）

- **更新探测依赖 E 站凭据**：未登录或凭据失效的用户会被跳过并记录日志，不会误标。
- 创建书签时若已存在同检索条件的书签，仅**提示可转移**，不自动替换（需手动确认）。
- 书签页三列布局在 1100px 以下降为两列、720px 以下单列，极窄屏仍偏挤。
- 「加载较新内容」锚点可能横跳一格（E 站每页 25 张与列数不整除所致，v2.2.0 起既有，接受现状）。
- 维护页疑似重复 / 推荐算法的既有单测存在顺序性偶发失败，与本次改动无关。
